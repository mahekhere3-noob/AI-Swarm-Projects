# 🤖 AI Swarm Projects

## 📌 Overview

This repository contains two AI-powered projects built using Swarm AI. Each project uses multiple specialized AI agents working together to perform different tasks efficiently.

## 🚀 Projects Included

### 🔬 1. AI Research Assistant

An AI-powered research assistant designed to help with research and information gathering. It uses specialized AI agents to break down research tasks and generate useful results.

### 📄 2. AI Resume Analyzer

An AI-powered resume analysis tool that evaluates resumes and extracts useful insights from their content. It can help analyze resume information and provide structured feedback.

## 🧠 Technology

Both projects use **Swarm AI** to coordinate multiple AI agents and assign specialized tasks to different agents.

## ✨ Features

- Multi-agent AI workflows
- Specialized AI agents
- Automated task execution
- Research assistance
- Resume analysis
- Structured AI-generated results

## 🛠️ Technologies Used

- Python
- Swarm AI
- Large Language Models (LLMs)
- AI Agents

## 🚀 How to Run

1. Clone this repository.

2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

3. Configure your required API keys/environment variables.

4. Run the desired project:

```bash
python ai_research_assistant.py
```

or

```bash
python ai_resume_analyzer.py
```
